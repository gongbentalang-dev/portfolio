# Photography Portfolio

## 概要
写真作品を「評価ではなく作品そのものに集中して見てもらう」ことを目的に制作したWebサイトです。  
閲覧者がストレスなく写真を楽しめるよう、シンプルで直感的なUIを意識しました。  

また、JavaScriptによる動的処理の理解に加え、運用のしやすさを考えた構造を意識して開発しました。  

---

## 使用技術
・HTML / CSS / JavaScript  
・Lightbox  

---

## 主な機能
・スライドショー  
・画像拡大表示（Lightbox）  
・左右ナビゲーション  
・EXIF情報の表示  
・簡易CMS機能（画像・情報の管理）  

---

## 工夫した点
・一覧に戻らず連続して閲覧できるUI設計  
・余計な情報を排除し、作品に集中できるレイアウト  
・EXIF情報を表示し、撮影意図や環境も伝わるよう設計  
・更新作業を効率化するため、管理しやすい構造を意識  

---

## 苦労した点
・Lightbox実装時のイベント制御の整理  
・EXIF情報の取得と表示処理の実装  
・表示崩れや動作不具合の原因特定に時間がかかり、試行錯誤を重ねた  

---

## 今後の課題
・画像数増加時のパフォーマンス最適化  
・コードの整理による保守性の向上  
・セキュリティ面を考慮した構成への改善  
・バックエンドを用いた本格的なCMS化
